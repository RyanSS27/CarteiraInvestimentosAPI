CarteiraInvestimentos

Uma forma simples de acompanhar sua carteira

Uma API REST desenvolvida em .NET para registrar operações de compra e venda de ativos da B3 e transformar esse histórico em uma visão consolidada da carteira.

O projeto registra as movimentações, calcula a posição de cada ativo e utiliza cotações de mercado para apresentar o valor atual e a rentabilidade da carteira.

.NET 10 C# 13 MongoDB API REST Arquitetura Hexagonal

Funcionalidades da aplicação

📝

Registre suas operações

Cadastre clientes e registre compras e vendas de ativos.

🗂️

Organize sua carteira

As operações são consolidadas automaticamente para identificar a quantidade atual e o custo médio de cada ativo.

📈

Consulte o valor atual

A aplicação consulta a Brapi para obter as cotações mais recentes disponíveis.

📊

Acompanhe seus resultados

Veja quanto foi investido, quanto a carteira vale atualmente e qual foi o lucro ou prejuízo de cada posição.

Registre suas transações e veja o resultado

1. Registre uma transação

Informe o ativo, quantidade, preço e tipo da transação (compra ou venda).

2. A aplicação processa o histórico

As compras e vendas são utilizadas para determinar a posição atual da carteira.

3. A carteira é consolidada

A aplicação calcula quantidade, preço médio e total investido.

4. A cotação é consultada

O preço atual do ativo é obtido através da Brapi.

5. O resultado é apresentado

A carteira passa a mostrar valor de mercado, lucro/prejuízo e rentabilidade.

🛡️

Pensado para continuar funcionando

A cotação de mercado depende de um serviço externo. Por isso, a aplicação possui um comportamento de fallback para situações em que a cotação não está disponível.

Quando isso acontece, a carteira continua sendo processada e o ativo afetado utiliza seu preço médio como referência. Assim, uma falha isolada não impede a visualização do restante da carteira.

Um projeto focado em desenvolvimento de APIs

Mais do que uma interface de investimentos, este projeto foi desenvolvido para demonstrar na prática a construção de uma API REST, persistência com MongoDB, integração com serviços externos e tratamento de diferentes cenários da aplicação.
